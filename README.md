# 智慧監造報表

單一檔案網頁（`index.html`），用瀏覽器（Chrome / Edge）直接開啟即可使用，需連網載入函式庫。

## 功能
| 分頁 | 內容 |
|---|---|
| 資料匯入 | ① 整合活頁簿一鍵匯入（工程資料、契約詳細表、預定進度、工程項目矩陣、記事、出工機具）② 契約詳細價目表／預算書（Excel 或 PDF）③ 預定進度表（Excel 或 PDF；直式欄／橫式列／貼上兩欄）④ 廠商施工日誌（整合活頁簿、本系統連動版、一日一頁標準施工日誌 Excel、施工日誌 PDF） |
| 契約項目 | 設定「需查驗」與「計量／比例」，顯示累計完成數量、完成率、查驗次數 |
| 施工日誌 | 逐日檢視與系統填報：天氣、施工概況等記事、出工機具、本日完成數量；自動計算本日／累計實際進度與預定進度 |
| 查驗填報 | 施工／材料查驗，表單號自動編號，勾選對應工項，可「帶入當日施工項目」；需取樣試驗者可回填試驗報告編號 |
| 試驗回填 | 所有待回填試驗報告，逾期標紅 |
| 技師督導、查核／團體督導 | 表單號、缺失件數、改善期限與完成日 |
| 職安衛／環保／交維／防汛 | 各類表單填報與編號 |
| 每週稽核 | 依施工日誌有數量的需查驗工項，比對前後 N 天內是否有查驗紀錄；列出未查驗日、試驗未回填、本週表單件數；可「補填查驗」、匯出稽核表 |
| 資料夾 | 公司共用的**實體資料夾**（放紙本的卷宗夾）採購統計：每個工程填一個數量，上方顯示總計，可匯出 Excel 給採購。不分種類與用途。這一頁不分專案，資料存在 RT-PMIS 的 Supabase，不需登入，同事填的數字即時同步（網路擋 WebSocket 時按「重新整理」）。Supabase 元件第一次進入此頁才下載 |
| 專案設定／匯出 | 工程資料、編號前綴、容許天數；匯出**整合連動版 Excel**（給廠商填每日數量與記事，公式自動算進度，可匯回）；JSON 備份與還原 |

## 預算書、預定進度表 PDF 匯入
- 預算書（詳細價目表）PDF：依表頭「項次／項目及說明／單位／數量／單價／複價」位置切欄；名稱折成多行（含儲存格垂直置中、上下分行）會自動併回同一工項。PDF 若只印整數單價，會以複價÷數量回推。PDF 沒有「項目代碼」欄，代碼依大項自動編（A01、B01…）。
- 預定進度表 PDF：支援直式（日期＋累計預定%欄）與橫式 10 日區塊（日期列＋累計列）；只寫「8/12」無年份者依開工日補年，請先填開工日期。只有 S 曲線圖、沒有數字的 PDF 無法讀取。
- 測試：以下崙北2路詳細表轉成的 PDF 匯入，88 項名稱、數量、類型全部與 Excel 一致。

## 施工日誌 PDF 匯入
- 限「文字型」PDF（由 Excel／Word 轉出者）；掃描影像檔沒有文字層，匯入時會提示該頁無法讀取，需先 OCR。
- 一個 PDF 可含多天：以每頁「填表日期」分日，未出現日期的續頁歸入前一天。
- 完成數量優先取第二聯（工程項目／契約單價／本日完成數量），無第二聯才取第一聯施工項目表；工項以名稱＋單價＋單位對應契約項目，名稱折行會自動合併。
- 同時讀取天氣、施工概況、取樣試驗、通知協力廠商、重要事項、出工人數與機具。
- PDF 元件於第一次匯入 PDF 時才下載，需連網。

## 進度計算
實際進度 ＝ Σ(計量項目完成數量×單價＋比例項目分攤金額) ÷ 契約項目總價，四捨五入至 0.01%。
比例項目（廠商利潤及管理費、營業稅）依排在其前方的所有項目當日完成比例分攤。
以下崙北2路 xlsm 驗證：115/09/16 累計實際 39.42%、預定 5.84%，與原活頁簿相同。

## 資料保存
資料存在瀏覽器（IndexedDB）。換電腦或同事共用：「專案設定／匯出」下載 JSON 備份放共用雲端硬碟，對方「還原／匯入備份」。

## 日後併入 RT-PMIS
程式內 `Store`（list / put / del）是唯一的存取層，換成 Supabase 呼叫即可；專案文件結構：
`info`、`items[]`（code, seq, name, unit, qty, price, group, kind, inspect）、`schedule[]`（date, cum）、
`logs{日期: {wAm, wPm, summary, safety, tests, notify, notes, labor{}, machines{}, qty{code: 數量}}}`、
`inspections[]`、`supervisions[]`、`forms[]`、`settings`。
